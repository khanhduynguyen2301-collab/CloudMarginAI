#
# WHY EXACT PINS (==) AND NOT RANGES (>=):
# Phase 1's exit gate is a byte-identical rerun from a fixed seed
# (docs/phase1/validation-plan.md, "Reproducibility test"). NumPy explicitly
# does NOT guarantee that `np.random.Generator` produces identical streams
# across feature releases — per NEP 19, only the legacy `RandomState` is
# frozen; Generator's stream may change when an algorithm is improved or a bug
# is fixed. So `simulate --seed 42` is only reproducible *within a pinned
# environment*. Loosen these pins and the exit-gate test can start failing on
# a machine that merely ran `pip install -U`.
#
# After installing, freeze the full resolved tree so transitive deps are
# pinned too:
#     pip freeze > requirements.lock.txt
